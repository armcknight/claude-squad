Everything you need at a glance

Stop juggling terminal tabs. See every session's status instantly.

⚠

Needs Input Alerts

Know immediately when Claude is waiting for your approval or has a question. Sessions needing attention are grouped at the top.

▶

Live Status Tracking

See which sessions are running, idle, waiting for input, or interrupted. Status updates automatically every few seconds.

💬

Full Transcripts

Read the complete conversation history for any session. See what Claude said, what tools it used, and what you asked.

☑

Task Progress

Track task completion across sessions. See how many tasks are done, in progress, or pending at a glance.

🔗

PR Links

Jump straight to the pull request for any session. Claude Squad detects PR URLs from the conversation automatically.

🔍

Project Grouping

Sessions are organized by directory in a collapsible tree. Multiple sessions in the same repo are grouped together.

How it works

1

Run Claude Code as usual

Keep using Claude Code in your terminal exactly as you do today. No plugins, no configuration, no changes to your workflow.

2

Claude Squad detects sessions automatically

The app reads Claude's local session files to detect every active session on your machine. It identifies the project, branch, and current status.

3

Monitor from the window or menu bar

Use the main window for a full overview with transcripts and details, or glance at the menu bar icon for a quick status check.
